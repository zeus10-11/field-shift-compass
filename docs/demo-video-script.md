**Recording tips**
- 1280×720 min, 30 fps; record the live app, not slides.
- Show cursor deliberately; let charts render before talking.
- Keep the backup recording of the same run (submit both links).
- Do not use SI-generated voice/visuals without visible watermark (see submission rules) — record your own voice.
